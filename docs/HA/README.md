# Home Assistant dashboard

Use the cards, tabs, and navigation on your dashboard as you normally would in Home Assistant. The visible controls depend on your Home Assistant configuration.

![Home Assistant dashboard shown in HA View](dashboard-overview.png)

Use HA View's menu to reach devices, entities, scenes, automations, and cameras. For dashboard layout and cards, use Home Assistant's dashboard editor.
