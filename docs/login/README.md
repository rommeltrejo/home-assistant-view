# Connect to Home Assistant

On first launch, enter your Home Assistant address and select **Save and open dashboard**.

![First-run dashboard address screen in HA View](first-run-url-setup.png)

If Home Assistant asks you to sign in, follow its sign-in screen. To change the dashboard address later, open HA View's settings.
