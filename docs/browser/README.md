# Browser

Select the globe icon on the dashboard to open the browser. Enter a website address and select **Go**. Use the arrows to go back or forward, and the circular arrow to reload the page. Use the page controls at the top of the screen to switch back to your dashboard.

![HA View browser address bar and navigation controls](browser-entry.png)

Select the gear to open the browser settings. There you can change:

- The **homepage** the browser opens first.
- The **search provider** used for searches.
- Whether the **browser icon** shows on the dashboard.
- **Clear browsing data** to remove stored website data.

With **Type to search** enabled, text that is not an address starts a search instead of failing to load.
