# Browser

Select the globe icon on the dashboard to open the browser. Enter a website address and select **Go**. Use the arrows to go back or forward, and the circular arrow to reload.

![HA View browser address bar and navigation controls](browser-entry.png)

Select the gear to change the homepage, search provider, and browser-icon visibility, or to clear browsing data. With **Type to search** enabled, text that is not an address starts a search.
