# HA View screen guide

This guide walks through HA View's screens in the order you will meet them. Start with connecting to Home Assistant; after that, everything else is a tap away.

1. [Connect to Home Assistant](login/README.md) — enter your dashboard address and sign in.
2. [Dashboard](HA/README.md) — use Home Assistant in HA View.
3. [Idle faces](faces/README.md) — choose a clock, calendar, events, or weather.
4. [Browser](browser/README.md) — open and navigate websites.
5. [Settings](settings/README.md) — set inactivity and face schedules.
